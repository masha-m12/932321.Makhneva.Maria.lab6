# 932321.Makhneva.Maria.lab6  

## Лабораторная работа №6. Введение в Node.js и базовый сервер на Express.  

### Описание работы  

Разработан сервер на Node.js с использованием Express, который раздаёт статические файлы и обрабатывает запросы к API. Выполнен «*Эхо-сервис*»: реализован маршрут /api/echo, возвращающий query-параметры в формате JSON. Также сайт «О себе» из предыдущих лабораторных работ был превращён в веб-приложение (PWA): добавлен манифест с иконками и Service Worker, обеспечивающий работу сайта в офлайн-режиме.  

### Реализация  

**Инициализация проекта:** настроен `package.json`, установлен `Express`, сервер запускается через `npm start`.  
**Маршруты:** `/about`, `/api/status` и `/api/echo` (возврат query-параметров).  
**PWA:** подключен `manifest.json`, приложение устанавливается на устройство (манифест с иконками).  
**Офлайн-режим:** статика (HTML, CSS, JS, картинки) кэшируется Service Worker'ом.  

### Запуск проекта  

1. Запустите сервер:  
```bash  
npm start  
```  
2. Откройте в браузере: `http://localhost:3000`.  

**Маршруты:**  
- `http://localhost:3000/api/status` — вернет JSON со статусом.  
```bash  
{  
  "status": "ok",  
  "message": "Сервер запущен"  
}  
```  
- `http://localhost:3000/api/echo?name=Maria&tags=js&tags=node` — вернет переданные параметры, а в терминале появится лог запроса.  
```bash  
{  
  "name": "Maria",  
  "tags": [  
    "js",  
    "node"  
  ],  
  "status": "ok"  
}  
```  

**PWA (Установка):** В браузере можно установить приложение и ярлык на рабочий стол.  

**Инструменты:** Node.js, Express, npm, терминал.
